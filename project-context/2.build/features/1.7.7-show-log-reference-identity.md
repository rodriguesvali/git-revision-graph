# 1.7.7 Show Log Reference Identity

Status: Implemented; automated and Extension Host verification passed

## Scope and acceptance

For a graph-selected target, Show Log retains the exact selected branch, head,
tag, remote, stash or commit identity in both all-branches modes. The host
validates the kind and authorizes the exact visible reference, then resolves its
namespace precisely on each load. A moved branch remains followable; a removed
reference fails rather than falling back to a namesake. Range logs and the other
review findings are outside this correction.

## Verification and risks

A real Git regression initially reproduced selection of the wrong namesake tag.
Tests now cover branch, annotated tag and remote collisions, both all-branches
modes, branch movement and deletion, and protocol validation and authorization.
On 2026-11-01, `npm test` passed 1,236 tests with no failures or skips, and
quality checks passed. Real VS Code 1.100.0 and 1.143.1 Extension Host safety
scenarios passed on Linux/Xvfb, including selecting same-name branch and tag
from the graph menu and toggling all branches. The overall safety scenarios
logged unhandled cancellation `AbortError` messages in separate repository
operation paths despite exiting successfully; this requires separate follow-up.
Windows/macOS and manual platform checks remain pending. `graphify update .`
passed. Rollback restores the previous short-name behavior.
