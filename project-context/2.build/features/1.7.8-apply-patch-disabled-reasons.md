# Apply Patch — Unavailable Reasons

Status: Implemented; automated verification passed; manual smoke confirmed by maintainer

## Scope and acceptance

When Apply Patch is blocked, show all known relevant conditions and next steps
in the graph context menu: conflicts or a conflicted merge, workspace changes
(including untracked files), and unsaved editors in the selected repository.
Keep the explained action keyboard-focusable and exposed as disabled to assistive
technology; pointer and keyboard activation must not dispatch the action. Keep
host-side checks and the enabled workflow unchanged. No protocol or Git changes.
