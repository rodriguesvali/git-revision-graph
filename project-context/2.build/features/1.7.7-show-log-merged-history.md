## Scope and acceptance

When Show Log opens a selected target with Show All Branches off, show all
commits reachable from that target, including merged side histories, while
excluding unmerged histories. With the option on, retain the existing all-ref
history. The selected target may differ from the checked-out branch. Filtering,
paging, range logs and commit actions retain their existing contracts. Git
ancestry cannot recover separate commits that were squash-merged or rebased
away; the reachable commits remain the source of truth.

## Implementation and verification

Remove first-parent traversal from target history; keep the option terminator,
bounded Git execution and the independent first-parent semantics used for merge
file/change comparisons. A real Git regression exercises a merged branch, an
unmerged checked-out branch, selected target, filtered and unfiltered results,
pagination and range scope. The regression failed before the change.
