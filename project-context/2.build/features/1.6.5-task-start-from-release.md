# Flow Governance: Start Task From Release

Status: Implemented; automated verification passed
Target version: `1.6.5`

## Goal

Allow a classified release branch to start a governed task branch for release-scoped work.

## Scope

- Expose `Flow Governance > Start New Task` on classified release references.
- Authorize task preparation, creation, and branch-text improvement only from known feature or
  release references.
- Reuse existing synchronization preflight, configured naming, collision checks, guarded mutation,
  optional publication, refresh, and source-target persistence.

## Non-goals

- Changing task support from features, task naming, Pull Request transition policy, or any other
  source-kind rule.
- Adding commands, settings, dependencies, provider APIs, automatic publication, or automatic
  merges.

## Acceptance Criteria

- A classified release exposes `Start New Task` and host authorization accepts the action.
- A task created from a release is checked out and retains that release as its source target.
- Feature-origin task behavior and unsupported source kinds remain unchanged.

## Verification

- Passed: focused Flow Governance coverage (141 tests), `npm run build`, `npm run quality:check`
  (263 files, 2,565 functions), `npm test` (876 tests), `graphify update .`, and
  `git diff --check`.

## Manual Validation

- In an Extension Development Host, select a synchronized release reference, create a task,
  decline publication, and verify the expected branch name and source release metadata.

## Release-Note Impact

Flow Governance can now start a task branch from a release branch.
