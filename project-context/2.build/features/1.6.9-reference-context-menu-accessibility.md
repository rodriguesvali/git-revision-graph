# Reference Context Menu Accessibility

Status: Implemented; automated verification complete; manual smoke pending

## Goal

Keep every reference-context action reachable when the graph webview has limited vertical space,
while reducing the common menu height without relocating reference-specific actions to the global
toolbar.

## User workflow

1. The user opens a reference context menu in a short graph panel.
2. The menu remains within the viewport and can scroll to every action.
3. Clipboard actions are available through `Copy`; branch/tag creation is available through
   `Create`.
4. A two-reference comparison still provides `Clear Selection`; a single selected reference can
   be deselected by clicking it again.

## Scope

- Constrain top-level and nested context menus to the webview viewport and enable contained
  vertical scrolling.
- Reuse the existing keyboard- and pointer-accessible submenu implementation for `Copy` and
  `Create` actions.
- Remove the redundant single-reference `Clear Selection` entry while preserving it for an active
  comparison.

## Non-goals

- Do not move reference-targeted Git actions to the responsive toolbar.
- Do not hide or reorder actions according to the current viewport height.
- Do not change the remote-tag, destructive-action, or Flow Governance action policies.

## Touched surfaces

- `src/revisionGraph/webview/runtime/contextMenu.ts`

## Acceptance criteria

- A context menu taller than the viewport is scrollable and all items remain reachable.
- `Copy Hash` and `Copy Ref Name` are exposed from the `Copy` submenu.
- `Create New Branch` and `Create Tag` are exposed from the `Create` submenu.
- `Clear Selection` remains in the two-reference comparison menu and is absent from the
  single-reference menu.
- Existing submenu keyboard navigation and viewport-aware placement remain intact.

## Risks

- Nested menus require pointer and keyboard smoke testing near every viewport edge.
- Scrolling must not propagate unexpectedly to the graph beneath the open menu.

## Test plan

- Run `npm test` and `git diff --check`.
- Verify generated-webview contracts for viewport bounds, submenu grouping, and comparison
  selection clearing.

## Manual validation

- In an Extension Development Host, open a dense branch context menu in a short panel; scroll to
  the final action and activate it.
- Check `Copy` and `Create` with mouse and keyboard, including right- and left-opening submenus.
- Compare two references and confirm `Clear Selection`; select one reference and clear it with a
  second click.
