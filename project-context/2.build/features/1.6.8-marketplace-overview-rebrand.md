# Marketplace Overview Rebrand

Status: Implemented; local package-surface verification complete; hosted preview pending
Last updated: 2026-08-23
Release target: `1.6.8`

## Goal

Present the current Git Revision Graph product clearly in the Visual Studio Marketplace without
mixing user-facing benefits with repository architecture, contributor setup, and test procedures.

## User Workflow

1. A prospective user opens the Marketplace Overview.
2. The hero statement and short video explain the graph, compare, and history workflow quickly.
3. Focused screenshots introduce Revision Graph, Compare Results, and Show Log.
4. Grouped capability sections cover Git actions, hosted remotes, Flow Governance, safety,
   requirements, and current boundaries without one exhaustive feature wall.
5. Contributors follow a separate link for local setup and verification.

## Scope

- Move the approved video, generated poster, and three product screenshots to
  `media/marketplace/`.
- Rewrite `README.md` as the Marketplace Overview for the `1.6.8` product surface.
- Embed the VP8/WebM video with absolute HTTPS `src` and `poster` URLs as required by the VS Code
  README media contract.
- Add concise grouped coverage of graph navigation, compare/review, Show Log, Git mutations,
  remote synchronization, hosted remotes, Flow Governance, optional AI, multi-repository behavior,
  safety, settings, and current boundaries.
- Move contributor setup, project mapping, Extension Host, and verification guidance into
  `CONTRIBUTING.md`.
- Exclude Marketplace media and contributor-only documentation from the VSIX while retaining them
  as public repository assets reached through HTTPS links.

## Non-Goals

- No runtime behavior, command, setting, contribution point, dependency, or extension icon change.
- No VSIX creation, source tag, Marketplace update, or publication command.
- No promise of unbounded history, provider support, or automated Git mutation beyond current
  behavior.

## Acceptance Criteria

- The Overview leads with value, video, and installation rather than internal architecture.
- The video uses the approved WebM/VP8 asset and branded poster through absolute HTTPS URLs.
- Three screenshots give Revision Graph, Compare Results, and Show Log distinct visual sections.
- Every major `1.6.8` product area is represented without reproducing every implementation detail.
- Contributor guidance remains available outside the Marketplace narrative.
- `npx vsce ls` includes `README.md` and excludes `media/marketplace/**`, `CONTRIBUTING.md`, and
  `project-context/**`.

## Risks

- Raw GitHub media URLs do not resolve until the assets are committed and pushed to the public
  repository.
- Marketplace and VS Code media rendering require network access to GitHub-hosted assets.
- Final rendering must be checked in both the Marketplace web page and VS Code Extensions view
  because local Markdown preview does not reproduce their sanitizer exactly.
