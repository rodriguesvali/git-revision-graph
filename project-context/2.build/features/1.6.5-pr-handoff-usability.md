# Pull Request Handoff Usability

Status: Implemented; automated verification complete
Target version: `1.6.5`

## Goal

Make the Flow Governance Pull Request dialog describe the real governed destination and the
provider-specific browser handoff before the user leaves VS Code.

## Scope

- Replace release-only target wording with neutral branch wording.
- Send a host-derived, credential-free provider handoff presentation with PR context.
- Describe prefilled GitHub, Azure DevOps, and GitLab handoffs and manual CodeCommit/Secure Source
  Manager handoffs.
- Offer copying the displayed source and target together for manual-provider workflows.

## Non-goals

- Provider APIs, authentication, automatic review creation, or changes to Git preflight policy.
