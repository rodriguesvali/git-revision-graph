# 1.6.7 Remove Promotion PR Context

Status: Implemented
Target version: `1.6.7`
Opened: 2026-08-15

## Goal

Remove the Flow Governance `Promotion PR Context` workflow after user feedback that its guarded
review form and provider handoff add more friction than value.

## Mapped Surface

- Flow Governance context-menu entries for feature, release, hotfix, package, task, bug, and
  equalization branches.
- Host/webview protocol messages, authorization, validation, controller dispatch, review dialog,
  hosted-provider URL handoff, and Pull Request-specific AI interactions.
- Generated Pull Request target state plus persisted branch target metadata used only by this
  workflow.
- User documentation and the relevant Extension Development Host smoke scenario.

## Scope And Acceptance Criteria

- Remove the menu action, dialog, protocol, host workflow, target discovery, and provider handoff.
- Stop writing and loading Pull Request-target metadata for new package, task, bug, and sync
  branches; existing local metadata is left untouched.
- Retain branch creation, branch descriptions, optional branch-description AI assistance, and
  equalization safeguards.
- A webview message for the removed action is rejected by validation and cannot perform Git or
  browser actions.

## Verification And Handoff

- `npm test` passed with 606 tests, including regression coverage that the shipped webview omits
  the action and that the protocol rejects its removed messages.
- `npm run build`, `npm run quality:check`, and `git diff --check` passed during implementation;
  the repository graph was refreshed after the final source changes.
- Pull Request-only AI prompts/context fitting were removed. The retained assistant accepts only
  Flow branch descriptions.
- The generic source-publication check reused by branch-start preflight was renamed so its contract
  no longer presents itself as Pull Request behavior.
- Manual smoke: Flow Governance menus expose only retained start/equalization actions and no
  Pull Request review form.

## Release-Note Impact

Document removal of `Promotion PR Context`; users use their normal repository Pull Request flow.
