# 1.6.7 Compact Revision Graph Search

Status: Implemented and stabilized
Target version: `1.6.7`
Opened: 2026-08-15

## Goal

Recover horizontal toolbar space while keeping graph search discoverable, keyboard-accessible, and
fully client-side.

## Behavior

- The persistent search field is replaced by an icon-only Find button in the graph toolbar.
- The button and `Ctrl+F`/`Cmd+F` open a floating search panel below the toolbar and focus its input.
- Closing the panel preserves the active query and exposes its current result position on the Find
  button; reopening restores the same query.
- `Escape` first clears a non-empty query and then closes an empty search panel.
- Clicking outside closes only an empty panel, so an active result set remains visible until the
  user explicitly closes it.
- Search remains browser-local and does not add extension-host messages, Git work, settings, or
  dependencies.

## Verification

Focused coverage exercises the shell/accessibility contract, typed search UI synchronization,
button and keyboard opening, query preservation, two-stage Escape behavior, and layout-profile
presentation. The full 835-test suite, production build, quality gate, and CI graph benchmark pass.
Manual Extension Development Host checks remain pending for narrow editor widths, themes, focus
order, and visual placement.
