# Azure DevOps Pull Request Handoff

Status: Implemented; verification pending
Target version: `1.6.6`

## Goal

Keep Flow Governance's remote safety preflight before its Pull Request form, without repeating
remote fetches when the user opens the browser handoff. Make the generated title and description
easy to transfer into Azure DevOps, whose browser URL only preselects the branches.

## Scope

- Retain target and source eligibility validation before showing the Pull Request form.
- Do not repeat remote preflight during the browser handoff.
- Explain the Azure DevOps branch-prefill limitation in the form.
- Add explicit Copy title and Copy description actions that preserve user edits.

## Non-goals

- Azure DevOps API authentication or automatic Pull Request creation.
- Changing Flow Governance target eligibility or source-publication policy.
