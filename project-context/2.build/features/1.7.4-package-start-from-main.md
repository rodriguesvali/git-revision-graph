# Flow Governance: Start Package From Main

Status: Implemented; automated and Chromium verification passed; Extension Host smoke pending
Target version: `1.7.4`

## Scope And Acceptance

The maintainer requested Package creation from `main`.

- Add `Start New Package` to main-classified references, including `master` or
  configured names classified as main. Retain the existing main actions.
- Allow preparation, preview and submission for known main sources; retain
  feature/release package sources and other guards.
- Reuse package exact-sync preflight, configured naming, required description,
  collision checks, guarded creation/checkout and confirmed optional publication.
- Keep unsupported source kinds rejected. No integration-policy, configuration,
  dependency, contribution-point or external API changes.

Ownership: `flowGovernanceMenu.ts` and `messageAuthorization.ts`.
Verify menu routing, all host form stages and creation from main, then build/full
tests, quality, Chromium form checks, graphify and diff whitespace checks.

Extension Host follow-up: create a Package from synchronized main, decline
publication, verify base/checkout/description; verify canceled synchronization.
Rollback is a scoped revert; preserve user-owned branches and Flow configuration.
