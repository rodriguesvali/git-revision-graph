# CI Cross-Platform Flow Config Path Reliability

Status: Implemented; local verification complete; hosted rerun pending
Last updated: 2026-08-23
Release target: `1.6.8`

## Goal

Keep the Flow Governance configuration-opening contract aligned with the canonical path returned by
the existing safe-persistence boundary on Linux, Windows, and macOS.

## Scope

- Canonicalize the test's expected newly created configuration path with `realpath()`.
- Preserve production path-safety behavior, including symlink and junction defenses.
- Do not change runtime behavior, dependencies, workflow structure, or GitHub Actions permissions.

## Acceptance Criteria

- The contract accepts equivalent canonical paths such as macOS `/private/var` versus `/var`.
- The contract accepts expanded Windows paths instead of requiring an 8.3 alias such as `RUNNER~1`.
- The opened and shown document assertions still require the exact canonical configuration path.
- The full local test and platform gates pass.

## Verification

- GitHub Actions run `#210` identified one failing test on Windows and macOS; both failures were
  non-canonical expected paths in the same orchestration contract.
- `npm test` passed all 838 tests on 2026-08-23, including the corrected orchestration contract.
- `npm run test:platform` passed all 39 tests on 2026-08-23.
- `npm run build` passed as part of the full test gate.
- A new hosted matrix run is required after the correction reaches GitHub.

## Release-Note Impact

None. This is a test reliability correction and does not change extension behavior.
