# Graph Comparison Discovery

Status: Implemented; automated verification passed; manual smoke pending

## Scope and acceptance

After the first graph revision selection, offer a dismissible hint for adding a
second revision with pointer or keyboard. Dismissal lasts for the webview session.
When two revisions are selected, offer Compare directly, in selection order,
using the existing comparison action and host authorization. Hide the controls
when inapplicable; dismissal must not suppress Compare. Preserve graph selection,
context menu, repository lifecycle and comparison direction. No protocol or Git
changes.

## Verification and handoff

dismissal, focus and the direct action after dismissal. On 2026-11-05,
`npm test` passed 1,251 tests including build; `npm run quality:check` and
