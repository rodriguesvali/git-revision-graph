# Show Log Search Help

Status: Implemented; automated verification passed on rerun; manual smoke confirmed by maintainer

## Scope and acceptance

Offer a keyboard-accessible native disclosure beside the Show Log search field.
Show selectable examples for metadata, repository-relative file paths, literal
changed text and combined filters; explain case sensitivity, quotes, renames and
search scope. Derive the displayed commit limit from the existing constant. Opening
help must not alter or execute the search. Preserve existing query behavior,
selection, paging and protocol.

## Verification and handoff

Focused shell coverage checks the disclosure, examples, parser compatibility and
limits. On 2026-11-05, `npm run quality:check` and `graphify update .` passed.
The first `npm test` run had 1,251 passes and one failure in the existing
`change search respects target, all-branches and range scope` Git test: an
unmerged commit was absent from its expected set. The isolated test passed and
a full rerun passed all 1,252 tests. History ordering relative to the selected
anchor is a possible cause, not confirmed. No search logic was changed.
On 2026-11-06, the maintainer confirmed that smoke testing of the implemented
UX improvements passed. Specific scenarios, platform, VS Code version and test
date were not supplied.
