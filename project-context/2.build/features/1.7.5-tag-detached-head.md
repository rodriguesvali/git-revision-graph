# 1.7.5 — Tag-Detached HEAD

Status: Implemented; automated verification passed; maintainer confirmed the fix works.
Reported: 2026-10-17, Angular screenshot with `fatal: malformed object name
refs/heads/v22.3.0-next.2` and a graph title identifying the tag as a branch.

## Cause and Scope

The built-in Git API can report detached HEAD as `{ type: Tag, name: <tag> }`.
The extension assumes any HEAD name is a current branch. The merge metadata
fallback then qualifies that tag as `refs/heads/<tag>` and can fail the graph load.
The same assumption affects title, overlays/status and branch-specific guards.

Centralize attached-branch interpretation using both type and name; preserve tag
references and detached browsing, keep branch-only controls unavailable, and
handle branches sharing a tag name correctly. Do not swallow Git errors or
change repository refs. Regression fixtures are disposable; the user's Angular
repository is not modified. Keep the approved minimum at VS Code 1.100.0.

## Sources and Acceptance

Context7 did not cover this Git API detail; exact official source confirms
`getHEADRef()` assigns the tag's name and `RefType.Tag` when HEAD is detached:
[VS Code 1.100 implementation](https://github.com/microsoft/vscode/blob/1.100.0/extensions/git/src/git.ts#L2363).

Prove the malformed-reference failure before the fix with real Git, then verify
graph load, title, overlays/status, same-name branch behavior and native tag
checkout in the real Extension Host. Retain plain detached and attached-branch
behavior. Run full tests, quality, benchmark and minimum/stable host checks.

## Implementation

- `getCurrentBranch` requires both `RefType.Head` and a name. Its upstream-label
  companion keeps the same rule in full and incremental graph state. The raw HEAD
  commit remains available for detached overlays and history identity.
- Apply that policy to merge metadata, graph references/title/status, published
  branch identity, checkout/create/reset/pull/push/sync guards and Flow source sync.
  Merge analysis also rejects a non-branch HEAD before its CLI fallback.
- A detached tag title is `angular: Detached HEAD (Tag: v22.3.0-next.2)`; a plain
  detached commit is `angular: Detached HEAD`. Attached branch titles retain their
  existing format. No protocol, dependency or contribution change is needed.
- The full/status builders share upstream extraction rather than expanding the
  state hotspot. Its measured file ceiling is tightened from 652 to 650; no
  complexity limit or verification threshold is weakened.
