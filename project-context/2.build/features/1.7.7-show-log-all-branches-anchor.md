# 1.7.7 Show Log All Branches Anchor

Status: Implemented; automated verification passed; manual smoke pending

When Show All Branches is enabled for a target, start at that selected commit
in Git's topologically ordered all-reference history. Entries above it are
excluded, including unrelated entries that happen to sort above the target;
other entries below remain eligible. Filter scans and pages use the same
boundary. Range logs and target-only traversal retain their existing behavior.

Resolve annotated tags and commit expressions to a full hash and include that
hash explicitly in both all-reference traversals, allowing detached commits.
Locate the boundary in bounded, cancellable batches, with an actionable error
if it is beyond 200,000 commits. Ref changes during subsequent loads can change
the ordering, as with the pre-existing paginated all-reference log.

The regression first failed on a real Git fixture with an annotated tag and a
later commit. Focused checks cover pagination, text and file filters, detached
commits and the existing range behavior. In the supplied CadCraft repository,
the first entry with `refs/tags/v0.15.1` and all branches enabled is `660e15c`,
followed by older history. Manual VS Code smoke remains pending.

`npm test` passed on 2026-10-31: 1,233 tests, zero failures or skips, including
production and webview builds. Quality checks and `graphify update .` passed.
Rollback restores the former unanchored all-reference query.
