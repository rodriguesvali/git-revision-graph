# 1.6.4 Flow Branch Form Validation

Status: Implemented; manual validation pending
Issue: GitHub #3

## Goal

Prevent Flow Governance task, bug, and hotfix forms from submitting a structured branch name when
the Short name field contains characters that cannot form a valid Git branch name.

## Scope

- Validate the Short name field in the browser runtime before a start-branch message is submitted.
- Keep the extension-host branch and configured-pattern validation as the authoritative final guard.
- Preserve the existing webview protocol and Git mutation workflow.

## Acceptance Criteria

- `Task 123456` is rejected in the form and focus returns to Short name.
- Git-invalid ref forms, including whitespace, control/ref characters, `..`, `@{`, dot-prefixed
  path segments, and `.lock` suffixes, are rejected before submission.
- A normal value such as `task-123456` remains accepted.
- Task, bug, and hotfix forms share the same validation.
