# 1.6.7 Revision Graph Layout Selector

Status: Implemented and stabilized
Target version: `1.6.7`
Opened: 2026-08-15

## Goal

Let users override the adaptive revision-graph layout profile when a repository topology benefits
from a different balance between crossing reduction and calculation speed.

## Preview Behavior

- A `Layout` combobox is visible beside `Scope` in the graph toolbar.
- `Automatic` remains the default and preserves the existing size- and shape-based selection.
- While automatic mode is selected, its option identifies the currently selected adaptive profile
  as `Automatic (Balanced)`, `Automatic (Faster)`, or `Automatic (Wide Graph)`.
- `Balanced`, `Faster`, and `Wide Graph` force the corresponding d3-dag profile.
- Changing the selection triggers a projection-only refresh and reuses the Git snapshot.
- The effective profile participates in the layout cache key.
- The selection lasts for the current graph panel lifecycle and is not written to repository config.

## Verification

The visual behavior was accepted before stabilization. Unit coverage now protects protocol
validation, projection propagation, projection-only refresh, effective profile and cache identity,
ready-state automatic-profile metadata, and webview selection synchronization and posting.
