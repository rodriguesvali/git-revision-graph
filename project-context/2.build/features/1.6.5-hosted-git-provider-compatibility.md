# 1.6.5 Hosted Git Provider Compatibility

Status: Open
Opened: 2026-08-09

## Scope

Patch-release compatibility work for hosted Git remotes:

- #4: recognize documented GitLab.com SSH host aliases.
- #5: derive GovCloud CodeCommit console URLs from GovCloud Git endpoints.
- #6: define a credential-safe experience for `git-remote-codecommit` `codecommit://` remotes, whose URL does not contain an AWS Region.

## Constraints

- Preserve credential-free hosted-remote parsing and URL construction.
- Do not read, store, or expose AWS credentials.
- Preserve existing provider formats, remote identity matching, URL encoding, multi-repository behavior, and Flow Governance safety guards.
- Do not package, tag, publish, or change Marketplace state without separate maintainer approval.

## Acceptance Criteria

- Each supported format has deterministic parser and URL-generation coverage.
- GovCloud links use the correct AWS console partition.
- Any `codecommit://` solution remains explicit about its region source and safe failure mode.
- `npm run build`, relevant tests, and `git diff --check` pass before release readiness is advanced.

## Initial Verification

- Baseline `npm test` passed before opening this version.
- No implementation, VSIX packaging, release tag, or Marketplace publication has occurred in this cycle.

## Implementation Record

### #4 GitLab.com SSH host aliases

- Implemented on 2026-08-09 in `src/hostedGitProviders/gitlab.ts`.
- SCP-style and `ssh://` remotes with a hostname ending in `.gitlab.com` now normalize to the
  canonical `https://gitlab.com/<namespace>/<repository>` page. This supports the documented
  SSH-config alias form while keeping HTTPS recognition restricted to the literal `gitlab.com`
  host.
- GitLab Self-Managed and arbitrary SSH hostnames remain unsupported because they cannot be
  safely reconstructed as GitLab.com browser URLs.
- Added exact commit and Flow Governance Merge Request URL regressions.
- Verification passed: `npm run quality:check` (263 files, 2,559 functions), `npm test`, focused
  compiled hosted-provider coverage (73 tests), `graphify update .`, and `git diff --check`.
- Manual Extension Development Host validation remains pending: configure a documented SSH alias,
  then open a GitLab commit and Flow Governance Merge Request handoff from an alias-backed remote.

### #5 CodeCommit GovCloud console URLs

- Implemented on 2026-08-09 in `src/hostedGitProviders/awsCodeCommit.ts`.
- CodeCommit remotes in `us-gov-east-1` and `us-gov-west-1` now derive the documented regional
  `console.amazonaws-us-gov.com` browser host. Commercial and China partition handling is unchanged.
- Added exact commit-link coverage for GovCloud SSH and FIPS HTTPS endpoints plus a Flow Governance
  Pull Request-area regression.
- Verification passed: `npm run quality:check` (263 files, 2,560 functions), `npm test`, focused
  compiled hosted-provider coverage (73 tests), `graphify update .`, and `git diff --check`.
- Manual Extension Development Host validation remains pending: open a GovCloud CodeCommit commit
  and Pull Request-area handoff from `us-gov-east-1` or `us-gov-west-1`.
