# Stable Flow form preview while typing — 1.7.1

Status: implemented; automated verification passed; visual retest pending
Date: 2026-09-05

## Define

Maintainer screenshots show the centered release form jumping vertically on each keystroke because
its multiline preview is replaced with a single loading line. Keep the form geometry stable and reduce
update churn while retaining configured naming, collision feedback and stale-response guards.

## Build

- `runtime/flowFormPreview.ts` preserves the current preview during edits in the same form/repository.
  Only an initial/new-session preview displays Loading. Debounce requests until 350 ms of inactivity.
  Mark the live region aria-busy while pending and clear it on completion/reset. Previous responses
  remain invalidated as soon as the input changes; reopening cannot reuse the previous form preview.
- `flowFormStyles.ts` reserves a 120 px preview box with internal scrolling and a stable scrollbar
  gutter. Loading, validation errors and longer names no longer resize/recenter the form. The existing
  dialog viewport scrolling remains available on short screens.
- Extend runtime regression coverage for retained text, rapid edits, stale results, busy-state cleanup
  and reopening. No protocol, Git operation, version or dependency changes.

## Deliver

`npm test` passed 917 tests including build and quality gates. `git diff --check` and
`graphify update .` completed successfully. Manual retest: type/delete release names at different speeds, trigger
name collisions, reopen and change repositories, and verify equalization, narrow/short viewports,
