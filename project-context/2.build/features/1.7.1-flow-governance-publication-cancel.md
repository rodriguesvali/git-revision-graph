# Flow form completion after publication cancellation — 1.7.1

Status: implemented; automated verification passed; reported manual regression pending retest
Date: 2026-09-05

## Define

Maintainer reproduced: create local release, accept publication, decline GitHub's permission-denied
fork offer; the creation form remains disabled at Processing. Preserve the local branch, deliver the
terminal form result, and avoid claiming that a cancelled publication succeeded.

## Diagnosis and Build

- `git.repositories` in the installed built-in Git extension maps to new Repository API wrappers on
  each access. The graph lifecycle reconciles the current wrapper during refresh. `FlowFormWorkflow`
  incorrectly used object identity for current-repository checks and silently discarded the final
  response after same-path refreshes. Use the existing repository path comparison instead, retaining
  disposal, different-repository and request-correlation guards.
- Installed GitHub push-error handling returns handled after the fork dialog is dismissed, so the
  Git API push promise can resolve even though no push succeeded. After push, inspect the new branch's
  upstream/ahead state before announcing publication; use the actual upstream remote (including fork).
  If unconfirmed, report local creation and direct the user to Source Control for the existing branch.
  Optional publication cancellation still completes local creation successfully and closes the form.
  Rejected pushes still produce a partial result; the form unlocks for closing and blocks recreation.
- External-contract evidence: installed server build
  `560a9dba96f961efea7b1612916f89e5d5d4d679`, `extensions/git/dist/main.js` repositories getter and
  `_push` handler; `extensions/github/dist/extension.js` handlePushError/handlePermissionDeniedError.
  Context7 resolution returned unrelated libraries; local shipped source and `src/git.ts` were used.
- Tests simulate same-path wrapper replacement for successful and partial completion, fork-offer
  cancellation resolving without upstream, successful fork upstream, and unavailable branch readback.
