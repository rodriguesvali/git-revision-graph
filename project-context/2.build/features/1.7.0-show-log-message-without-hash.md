# 1.7.0 Show Log Message Without Hash

Status: Implemented; automated verification complete, manual smoke pending
Last updated: 2026-09-04

## Goal

Reduce visual noise in compact Show Log rows by presenting the commit subject without a short-hash
prefix.

## User Workflow

The user scans commit messages directly. Hover and context actions still provide commit identity and
copy operations when needed.

## Scope

- Remove the short hash from the primary commit-message line.
- Remove CSS used exclusively by that inline hash.
- Preserve the short hash in the tooltip and the full hash in copy, remote, selection, comparison,
  reset, and internal row-identification workflows.

## Non-goals

- No change to Git loading, commit identity, tooltip contents, actions, dates, authors, references,
  graph topology, or row height.

## Touched Surfaces

- `src/showLogWebview.ts`
- `src/showLog/webviewStyles.ts`
- `test/showLogWebview.test.ts`
- Release documentation

## Acceptance Criteria

- A Show Log row begins with the commit subject and contains no `commit-hash` element.
- The tooltip continues to display the short hash and copy the full hash.
- Commit actions and data attributes continue using the full commit identity.

## Risks

- Removing the always-visible hash reduces at-a-glance identity; tooltip and Copy Commit Hash remain
  the deliberate retrieval paths.

## Test Plan

- Assert absence of the row hash and presence of subject and tooltip hash markup.
- Run focused Show Log tests, `npm test`, `npm run quality:check`, `git diff --check`, and
  `graphify update .`.

## Manual Validation

Open Show Log and verify compact, referenced, selected, and expanded rows; hover a commit and copy its
hash from the tooltip or context action.

## Release-note Impact

Show Log commit rows now lead directly with the message instead of its short hash.
