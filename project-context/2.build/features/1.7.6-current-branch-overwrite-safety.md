# Current branch overwrite safety

The remote checkout flow can overwrite an existing local branch. When that branch
is checked out, it uses a hard reset. The flow now requires a clean workspace
both before asking for confirmation and after confirmation, before the reset.
Other checkout and branch creation paths retain their existing dirty-worktree rules.

The guard uses the existing vscode.git repository state and conflict checks. It
cannot make the state check and reset atomic against external Git operations or
filesystem changes. No new dependencies, commands, or configuration are added.

Regression tests cover unstaged, staged and untracked changes before and during
confirmation; clean overwrite and cancellation retain existing coverage. On
2026-10-28, `npm test` passed 1,220 tests, `npm run test:platform` passed 53,
and `npm run quality:check` passed. A temporary Git fixture confirmed that a
dirty tracked file is preserved, a warning is shown, and reset is not invoked.
