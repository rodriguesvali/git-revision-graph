# Flow Governance: Start Package From Release

Status: Implemented; automated verification passed
Target version: `1.6.5`

## Goal

Allow a classified release branch to start a governed package branch for release-scoped validation
or consolidation work.

## Scope

- Expose `Flow Governance > Start New Package` on classified release references.
- Authorize package preparation, creation, and branch-text improvement only from known feature or
  release references.
- Reuse the existing exact-sync preflight, configured naming, collision checks, guarded mutation,
  optional publication, refresh, and target persistence.
- Persist the originating release as the package promotion target.

## Non-goals

- Changing package support from features, package naming, Pull Request transition policy, or other
  source-kind rules.
- Adding commands, settings, dependencies, provider APIs, automatic publication, or automatic
  merges.

## Acceptance Criteria

- A classified release exposes `Start New Package` and host authorization accepts the action.
- A package created from a release is checked out and retains that exact release as its target.
- Feature-origin package behavior and unsupported source kinds remain unchanged.
