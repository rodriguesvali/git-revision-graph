# Responsive Toolbar Action Groups

Status: Implemented; automated verification and maintainer smoke complete
Target version: `1.6.9`
Opened: 2026-08-25

## Goal

Keep repository actions and zoom controls as independent responsive toolbar groups so zoom moves to
the next row before repository actions must move or split under reduced horizontal space. Keep the
graph, floating search, and subtle progress surfaces aligned immediately below the toolbar's actual
rendered height at every width.

## User Workflow

When the Revision Graph editor narrows, the repository-action group retains its first-row position.
The complete zoom group moves to the next row first. Only when the editor becomes narrower still do
repository actions need to move to a later row.

## Scope

- Make repository and zoom action groups sibling flex items in the toolbar.
- Preserve repository-before-zoom order and keep each group intact.
- Replace width-based toolbar-height estimates with its measured rendered border-box height.
- Resynchronize viewport sizing and placement when toolbar wrapping changes its height.
- Render the supplied reset-zoom SVG inline so it inherits the active workbench theme color.
- Cover the generated markup and responsive CSS contract.

## Non-goals

- Do not alter action behavior, shortcuts, labels, or accessibility names.
- Do not change graph layout, zoom behavior, or toolbar contents.
- Do not add commands, settings, dependencies, or Marketplace actions.

## Acceptance Criteria

- Repository actions and zoom controls are separate direct flex items of the toolbar.
- Zoom controls wrap as a complete group before repository actions at constrained widths.
- The graph viewport, floating search, and subtle progress offset follow the measured toolbar height
  without premature gaps at the former 1,100 px and 820 px thresholds.
- Existing button identifiers, order within groups, labels, and behavior remain unchanged.
- The reset-zoom glyph uses the supplied SVG and inherits `currentColor` from the toolbar.

## Risks

- Structural changes could detach existing interaction hooks or accessible labels.
- Toolbar measurement must ignore non-positive transient dimensions and avoid resize feedback loops.

## Test Plan
