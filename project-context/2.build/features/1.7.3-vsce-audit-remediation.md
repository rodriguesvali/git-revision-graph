# VSCE Audit Remediation — 1.7.3

Status: Implemented and verified; release published by maintainer confirmation
Date: 2026-10-03

## Scope and Acceptance Criteria

The maintainer authorized upgrading the development dependency `@vscode/vsce`
from `3.9.2` to `4.0.0` to remove the vulnerable braces dependency chain.
Update the manifest and lockfile while preserving existing user lockfile edits,
extension version `1.7.3`, runtime dependencies and VS Code engine `^1.90.0`.

Acceptance: full and runtime audits report zero vulnerabilities; clean installation,
build and existing tests pass; `vsce ls` preserves package inclusion; the package and
publish CLI commands remain available. No production behavior change is intended.

## Compatibility and Verification Plan

Context7 `/microsoft/vscode-vsce` confirms Node 22+ and the replacement credential
backend `@napi-rs/keyring`; local and CI Node 24 satisfy the engine requirement.
The retrieval did not fully cover version-specific CLI and scanning changes, so
verify those contracts against installed 4.0.0 source, CLI help and package preview.
Reference: https://github.com/microsoft/vscode-vsce/releases/tag/v4.0.0.

Install with lifecycle scripts disabled, inspect required lifecycle hooks before
execution, and verify with a frozen lockfile install. Compare file-list previews
before and after the upgrade. Run `npm test` including build, both audits and final
diff checks. Deterministic checks are sufficient; no Jev judgment is required.

## Delivery and Rollback

VSIX creation, installation and Marketplace publication require separate approval;
this dependency correction did not authorize them. Delivery evidence from the later
release is recorded below and in release readiness.
Rollback only this dependency and its lockfile changes, preserving prior user edits;
the previous development toolchain would reintroduce the recorded audit finding.

- Final diff checks passed. Self-review followed `code-review-and-quality`:
  package scripts, VS Code engine, runtime dependency graph and package inclusion

An intermediate file-list comparison ran during the build's output cleanup and
