# Show Log No-Results Recovery

Status: Implemented; automated verification passed; manual smoke pending

## Scope and acceptance

For a visible, settled search with no results, offer Clear search beside the
existing empty message, including the honest truncated-history warning. Reuse
the existing debounced, source-scoped filter update and restore focus to the
search field. Do not show the action for an unfiltered empty history, loading,
hidden view or error. Do not imply older history can be searched beyond the
existing limit. Preserve protocol, paging and selection behavior.
