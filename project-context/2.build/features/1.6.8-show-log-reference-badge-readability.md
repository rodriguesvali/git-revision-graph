# 1.6.8 Show Log Reference Badge Readability

Status: Implemented; automated verification complete; manual smoke pending
Target version: `1.6.8`
Opened: 2026-08-23

## Goal

Let users read complete long reference names in the existing Show Log commit tooltip without
reducing the density of commit rows or introducing a competing tooltip.

## User Workflow

1. A long branch, tag, or remote reference remains compact and ellipsized in the commit row.
2. The user hovers the commit and opens its existing delayed tooltip.
3. Reference badges in the tooltip expand up to the available tooltip width.
4. Exceptionally long unbroken names wrap safely instead of overflowing the viewport.

## Scope

- Keep the row badge default at 180 px with single-line ellipsis.
- Override badge maximum width and wrapping through CSS properties scoped by the commit-tooltip
  reference container.
- Add a focused Show Log webview regression for the row and tooltip policies.

## Non-goals

- No second reference tooltip, overflow measurement, interaction, protocol, data, or Git change.
- No change to badges that are completely hidden when a row contains more references than fit.
- No command, setting, contribution point, dependency, or package-version change.

## Touched Surfaces

- `src/showLog/webviewStyles.ts`
- `test/showLogWebview.test.ts`
- Focused build and release documentation

## Acceptance Criteria

- Row badges retain the existing compact maximum width and ellipsis behavior.
- Commit-tooltip badges can use the full tooltip width.
- Long names wrap at safe character boundaries and stay within the tooltip viewport bounds.
- Existing tooltip timing, content, actions, reference icons, and colors remain unchanged.

## Risks

- Very long references may make the commit tooltip taller; viewport-aware tooltip positioning
  already constrains its placement.
- Multi-line reference pills require light/dark theme and narrow-panel smoke validation.

## Test Plan

- Assert the default row badge CSS and the commit-tooltip CSS property overrides.
- Run `npm run quality:check`, `npm run build`, `npm test`, `graphify update .`, and
  `git diff --check`.

## Manual Validation

- Open Show Log with long local, remote, tag, and HEAD reference names.
- Confirm rows remain compact and the commit tooltip shows each name in full.
- Validate narrow and wide panels, multiple wrapping references, and light/dark themes.

## Release-note Impact

Show Log commit tooltips now display complete long reference names while commit rows remain compact.
