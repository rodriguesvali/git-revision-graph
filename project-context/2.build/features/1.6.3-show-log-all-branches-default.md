# 1.6.3 Show Log All-Branches Default

Status: Implemented; automated validation complete; manual smoke pending
Last updated: 2026-08-01
Baseline: `1.6.3` release cycle

## Goal

Open target-based Show Log histories with `Show All Branches` enabled by default so commits from
other branches are immediately visible without an extra toggle action.

## Scope

- Initialize every new visible Show Log source with `showAllBranches: true`.
- Keep the checkbox editable for target sources.
- Preserve range behavior, where all-branches state remains enabled and the toggle stays hidden.
- Preserve explicit user toggling, filtering, paging, refresh, and source replacement behavior.

## Acceptance Criteria

- Opening Show Log for a target sends `showAllBranches: true` to the first history load.
- The visible target state renders `Show All Branches` checked.
- The user can uncheck the option and reload the target-only first-parent history.
- Range histories remain unchanged.

## Verification

- Cover the initial target state and backend load argument in the Show Log orchestration suite.
- Run `npm run quality:check`, `npm run build`, `npm test`, `git diff --check`, and
  `graphify update .`.

## Manual Validation

- Open Show Log for a branch in an Extension Development Host and confirm `Show All Branches` is
  checked before interaction.
- Uncheck and recheck it, confirming the history reloads with the corresponding scope.
